# سجل الخبير 0.9.17 — تجربة أسبوع ثم Google

## السلوك المعتمد

- تجربة واحدة دون حساب لمدة سبعة أيام كاملة، تبدأ بعد قبول رسالة الحذف.
- قاعدة بيانات ومرفقات وتفضيلات التجربة منفصلة عن بيانات الحساب.
- بعد انتهاء التجربة: إغلاق الوصول وحذف بيانات التجربة الداخلية، ثم اشتراط Google للاستمرار.
- سجل انتهاء التجربة خارج البيانات المحذوفة؛ لا يجدد تسجيل Google الموعد.
- لا يوجد تخطي غير محدود أو دخول بكود تفعيل. علامة Preview القديمة لا تمنح دخولًا.
- تسجيل الدخول يقتضي جلسة Firebase غير مجهولة ومزوّد Google، وتُحجب كل شاشات العمل عند فقد الجلسة أو انتهاء التجربة.
- بيانات الحساب تبقى محلية؛ تسجيل Google وحده لا يضمن نسخة سحابية.
- لا نقل تلقائي لبيانات التجربة للحساب، ولا حذف للملفات التي صدّرها المستخدم خارج التطبيق.
- الحذف الخلفي يخضع لجدولة Android؛ بعد الإيقاف الإجباري ينفذ عند التشغيل التالي قبل فتح مساحة العمل.

## هوية الإنتاج

الحزمة `com.khabir.app.combined`، اسم التطبيق «سجل الخبير»، الإصدار `0.9.17` ورقم البناء `108`، Target SDK 36 وMin SDK 26. الإنتاج يستخدم توقيع Upload ثابت وAPK/AAB من نفس البناء. APK التجربة له حزمة Preview منفصلة ولا يساوي ملف Play الإنتاجي.

## إعدادات ما زالت مطلوبة من مالك الحساب

1. ملف `google-services.json` لتطبيق Android بالحزمة الإنتاجية، وGoogle OAuth Web Client ID وتفعيل Google داخل Firebase Authentication.
2. مفتاح التوقيع القائم إذا سبق نشر التطبيق؛ لا يُستبدل بمفتاح تجريبي. تسجيل SHA-1/SHA-256 لشهادة APK موزع عبر Firebase، ولشهادة App Signing من Play.
3. روابط HTTPS فعلية لخدمة التطبيق وسياسة الخصوصية وطلب حذف الحساب، وإعدادات AdMob والاشتراكات المطلوبة.
4. تأكيد أن الحزمة الحالية لم تُنشر باسم مختلف في Play Console، وتوفير بريد دعم عام.

لم تُوفّر هذه الإعدادات الحقيقية في المحادثة أو ملفات الإصدار. نجاح فحص CI ببيانات وهمية لا يثبت عمل تسجيل Google، ولا يجوز تسليم AAB الاختبار على أنه إصدار نشر.

## مسار التسليم

- APK التجربة للتجريب: من Android CI بعد نجاح الاختبارات وفحوص الملف.
- APK الإنتاج لتوزيع Firebase وAAB للمتجر: من Android Release بعد إعداد الأسرار الحقيقية واجتياز `verify_release_config.py`.
- لا رفع لمختبرين أو إرسال دعوات ضمن هذه المهمة؛ الملف يُجهز للمراجعة والرفع.
