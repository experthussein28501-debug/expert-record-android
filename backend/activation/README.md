# تفعيل الوحدة الأولى

الحالة: تنفيذ قابل للاختبار، لم يُنشر على خادم بعد. لا توجد أكواد عامة داخل APK.

## التشغيل

يتطلب Python 3 وخادمًا بقرص دائم وواجهة HTTPS أمام الخدمة المحلية.

```sh
python3 service.py --db /srv/khabir/activation.sqlite3 issue --seats 1
python3 service.py --db /srv/khabir/activation.sqlite3 serve --port 8080
python3 -m unittest -v
```

تُظهر أداة الإصدار الكود مرة واحدة؛ قاعدة البيانات تحفظ بصمته فقط.
أداتا `disable` و`release-device` تطلبان الكود بصورة مخفية.
إلغاء الكود يمنع التفعيلات الجديدة فقط. الأجهزة المفعلة تعمل محليًا،
ولا يُنفّذ سحب تفعيلها عن بعد؛ لا يوجد اتصال يومي بالخادم.
نقل المقعد لا يعطّل الجهاز القديم وهو غير متصل.

معرف الجهاز عشوائي خاص بالتثبيت، وليس رقم الهاتف أو معرفًا عتاديًا.
إعادة التثبيت قد تتطلب تحرير المقعد القديم. يجب استثناء تفضيلات التفعيل
من النسخ الاحتياطية، وإتاحة معرف التثبيت للإدارة عند طلب النقل.

قبل النشر: ضع الخدمة خلف HTTPS مع حدود حجم الطلب ومعدل الاتصالات
ومهلة للاتصال. لا تثق برؤوس عنوان IP يرسلها العميل. المحدد الداخلي
يستخدم عنوان الاتصال؛ خلف proxy واحد سيكون الحد مشتركًا حتى تُضبط
طبقة proxy موثوقة مع تحديد معدل مستقل لكل عميل.
احمِ قاعدة البيانات بصلاحيات نظام التشغيل وخذ نسخًا احتياطية لها.
لا توجد واجهة إدارة عامة أو مفاتيح إدارة مضمنة في التطبيق.

أدخل عنوان HTTPS الكامل المنتهي بـ `/activate` في خاصية Gradle
`KHABIR_ACTIVATION_ENDPOINT` ثم أعد بناء التطبيق.
تسجيل Google يحتاج إعداد Firebase مستقلًا؛ هذه الخدمة لا تدّعي إنشاءه.
التخطي يبقى متاحًا، وبالتالي الأكواد لإدارة تجربة أولية وليست حاجز اشتراك.
