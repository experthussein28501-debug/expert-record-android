- `namespace`: `com.khabir.app`.
- التطبيق المسجل في Manifest: `com.khabir.app.KhabirApplication`.
- شاشة التشغيل المسجلة: `com.khabir.app.MainActivity`.
- اسم التطبيق الظاهر: `سجل الخبير`.
- قاعدة البيانات الفعلية: `khabir.db`، الإصدار 7.

## التداخل المكتشف

يوجد مصدر قديم موازٍ داخل نفس Module تحت الحزمة `com.expert.casemanager`، ويشمل:

- `MainActivity` ثانية.
- `ExpertCaseApp` وتنقل مستقل.
- `ExpertDatabase` وقاعدة بيانات مستقلة.
- Models وDAO وRepository وشاشة أقسام مستقلة.

هذا المسار ليس المسجل في AndroidManifest، لكنه يدخل في تجميع الكود ما دام تحت `app/src/main/java`. القرار التنفيذي: يُعزل أولًا في فرع الاستعادة بعد مقارنة أي وظيفة غير منقولة منه، ثم يُحذف من مصدر الإنتاج في Commit مستقل قابل للرجوع.

## حالة الوحدات الفعلية

| الوحدة | الموجود | المشكلة المطلوب إغلاقها |
|---|---|---|
| بيانات الخبير | حفظ محلي أساسي | الحقول ناقصة ولا توجد Snapshot كاملة للمخرجات القديمة |
| القضايا | CRUD وبحث وخصوم | مسودة/تحقق التكرار/استعادة الحالة تحتاج تثبيت واختبار |
| OCR | خدمة Tesseract وParser | النسخة المستقرة تعتمد على تنزيل اللغة وصورة منخفضة الدقة في بعض التدفقات |
| الإخطارات | بيانات وWord builders | المطابقة البصرية والتجربة الفعلية غير مغلقتين |
| التقارير | حقول ثابتة وWord/PDF | لا توجد قوالب أنواع مرنة ولا أقسام قابلة للتعديل والحذف والترتيب |
| السجلات | فلترة وWord أساسي | يلزم تثبيت التصنيفات والمطابقة والطباعة |
| الإدارة | غير منفذة | مرحلة لاحقة بعد إغلاق الوظائف المحلية |

## عائق البناء المحلي الحالي

نسخة الملفات المحلية لا تحتوي Gradle Wrapper، وأمر `gradle` غير مثبت في بيئة العمل؛ لذلك لا يجوز الادعاء أن البناء المحلي نجح من هذه النسخة. التحقق سيجري عبر ملفات Wrapper الموجودة في المستودع/إعادة جلب نسخة Git كاملة أو GitHub Actions، ثم توثيق رقم التشغيل ونتيجته.

## أول أعمال التنفيذ

1. مقارنة الحزمة القديمة بالحزمة الفعلية وحفظ أي وظيفة مفيدة قبل عزلها.
2. تثبيت Wrapper/مسار بناء قابل للتكرار وتشغيل الاختبارات الموجودة.
3. إضافة اختبارات Migration قبل تغيير قاعدة البيانات.
4. البدء ببيانات الخبير والدعوى والخصوم حسب المرحلة 1–3 من الخطة.

## شرط إغلاق المرحلة صفر

- فرع استعادة مستقل ومعلوم الأصل.
- مسار تطبيق واحد فقط في Source Set الإنتاجي.
- Build واختبارات موثقة من نفس الفرع.
- عدم فقد أي وظيفة من النسخة القديمة.
- رقم إصدار اختبار جديد وهوية تثبيت لا تتعارض مع النسخة الموجودة على الهاتف.
