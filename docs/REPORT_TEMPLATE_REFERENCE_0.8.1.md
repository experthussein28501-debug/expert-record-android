# مرجع قوالب التقارير — 0.8.1

القالب الافتراضي يحدد **ترتيب وعناوين** التقرير فقط. نص كل قضية يظل خاصًا بها ويُراجع قبل الاعتماد.

## مدني
العينات المرجعية:
- الدعوى رقم 146 لسنة 2025 مدني جزئي نصر النوبة.
- الدعوى رقم 205 لسنة 2024 مدني جزئي نصر النوبة.

البنية المتكررة:
الموضوع → المأمورية → مباشرة المأمورية → أقوال طرفي التداعي → المعاينة على الطبيعة → بحث المستندات → البحث → النتيجة النهائية.

«الوقائع والملاحظات» و«الحسابات والجداول» بنود اختيارية.

## جنح
العينة المرجعية:
- الجنحة رقم 7845 لسنة 2014 جنح مركز كوم أمبو.

البنية:
الموضوع → المأمورية → مباشرة المأمورية → أقوال المتهم → أقوال محرر محضر المخالفة → المعاينة على الطبيعة → أقوال الشهود → النتيجة النهائية.

«فحص المستندات» و«البحث» يظلان متاحين لكن غير مفعّلين افتراضيًا.

## مدني مستأنف
العينة المرجعية:
- الدعوى رقم 305 لسنة 33ق مدني استئناف أسوان.

القالب يحتفظ ببيان الحكم المستأنف والتقارير السابقة، ويفصل أقوال المستأنفين عن المستأنف ضدهم، ويقسم بحث المستندات حسب المصدر.

## استئناف عالٍ
العينات المرجعية:
- الدعوى رقم 871 لسنة 34 استئناف عالٍ قنا — مأمورية استئناف أسوان.
- الدعوى رقم 1276 لسنة 23ق س ع قنا — مأمورية أسوان.

له قالب مستقل لأن مسار الطعن والإعادة والتقارير السابقة قد يكون جزءًا أصيلًا من الموضوع والبحث والمأمورية.

## ضوابط
- لا يوجد بند «الرأي الفني».
- لا تُختلق وقائع أو نتائج.
- المعاينة والرسم/الخريطة مكانهما بند المعاينة.
- النتيجة النهائية غير قابلة للحذف.
