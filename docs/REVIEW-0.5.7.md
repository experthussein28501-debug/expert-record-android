# مراجعة 0.5.7 — العمل غير معتمد كتسليم نهائي

## Gemini

نجحت اختبارات الكود وبناء APK واختبار OCR لمحرك Android في تشغيل
GitHub Actions رقم 34535137642، للكود e36e20757e629d689dfa1e7b111be25ccea67b3a.
تتضمن الاختبارات أولوية Flash-Lite، عدم التصعيد إلى Pro، المحاولة بنموذج آخر
عند 404 أو 429 المحدد بحصة نموذج، والتوقف عند حد غير محدد النطاق.
هذه استجابات اختبار محاكاة وليست اختبار مفتاح Gemini حقيقي أو مستندات المستخدم.
الترتيب حسب عائلة النموذج والاستقرار، وليس مقارنة أسعار مباشرة لكل إصدار.

## تغييرات تالية تحتاج بناء Android جديد

- ربط زر التفعيل بخدمة HTTP عبر HTTPS بدل مقارنة كود ثابت داخل التطبيق.
- منع حفظ نتيجة اختبار مفتاح سبق تغييره أو حذفه أثناء الاتصال.
- حذف مسارات الإخطارات والتقارير من مخطط التنقل عند MODULE_MODE=ARCHIVE.
- رقم الإصدار 0.5.7 (47).

## خدمة التفعيل

اختبارات محلية ناجحة: إعادة تفعيل الجهاز نفسه، منع تجاوز المقاعد تحت التزامن،
إلغاء الكود ونقل المقعد، الحد من المحاولات، وعدم حفظ الكود كنص صريح.
الخدمة غير منشورة. يلزم خادم دائم مع HTTPS وربط KHABIR_ACTIVATION_ENDPOINT.
إلغاء الكود لا يسحب التفعيل المحلي من أجهزة تعمل دون اتصال.
التخطي متاح؛ هذا تنظيم للتجربة وليس نظام اشتراك ملزمًا.

## موانع الاعتماد النهائي

- لم يُربط مشروع Firebase وGoogle Web Client بإعدادات البناء.
- لم تُنشر خدمة التفعيل أو تختبر من هاتف عبر HTTPS.
- اختبار Gemini الفعلي بمفتاح ذي حصة وصور قضايا مختلطة غير منفذ.
- الكاميرا والاستيراد وLens ولوحة المفاتيح تحتاج اختبارات على هاتف.
- فحص مسارات التنقل لا يثبت إزالة كود الوحدات اللاحقة من الحزمة الثنائية.
- بقية حالات قبول المستندات والتصدير والنسخ الاحتياطي لا تعد معتمدة بهذه المراجعة.

لا يجوز تقديم نجاح CI باعتباره اكتمال جميع متطلبات الوحدة الأولى.
