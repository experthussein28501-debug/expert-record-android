# الأسرة وقوالب Word الشخصية — 0.8.2

## قالب أحوال شخصية / شئون الأسرة
تمت إضافة القالب بعد مراجعة تقارير فعلية من Drive، منها:
- الدعوى رقم 77 لسنة 2025 محكمة دراو لشئون الأسرة.
- الدعوى رقم 21 لسنة 2024 محكمة أسوان لشئون الأسرة.
- الدعوى رقم 164 لسنة 2017 محكمة كوم أمبو لشئون الأسرة مال.
- الدعوى رقم 3ح لسنة 2020 شئون الأسرة — مال دراو.
- تقرير تركة المرحوم عبدالله علام حسين.

الترتيب الافتراضي:
الموضوع → المأمورية → مباشرة المأمورية → الأقوال → المعاينة على الطبيعة → بحث المستندات → البحث → النتيجة النهائية.

بنود اختيارية:
- أقوال الشهود.
- بيان عناصر التركة والورثة.
- حساب نصيب القصر والريع.

القالب قابل لإعادة تسمية البنود، الإخفاء، الإضافة، الحذف، وإعادة الترتيب مثل باقي قوالب التقرير.

## قالب Word الشخصي
بدل قالب Word واحد عام، يحفظ التطبيق قالب Word مستقلًا لكل Report Template ID. بذلك يستطيع كل خبير الاحتفاظ بقالب Word خاص لكل نوع تقرير، بما في ذلك أي قالب مخصص ينشئه بنفسه.

يحفظ لكل نوع:
- URI ملف Word.
- Mapping بين فقرات النموذج وحقول التقرير.

قالب 0.8.1 القديم يُرحّل مرة واحدة إلى نوع التقرير الذي يفتحه الخبير، ثم تُحذف المفاتيح العامة القديمة لمنع استخدام نفس القالب خطأً في نوع آخر.

## قاعدة المراجعة قبل الاعتماد
قاعدة العمل ثابتة: **اقتراح → مراجعة → اعتماد**.

- AI Assistant: شاشة مراجعة لما سيرسل قبل الاتصال، ثم مراجعة الرد قبل استخدامه.
- OCR / AI Vision: النص المستخرج يذهب إلى شاشة مراجعة قبل إدخاله في أي قسم.
- Word import: شاشة مراجعة وتحديد القسم قبل الاعتماد.
- Excel import: شاشة تعرض الحقول المستخرجة قبل الاعتماد.
- Word template mapping: شاشة فوقية لاختيار الحقول والفقرات قبل إنشاء النسخة.
